# Raster documents to PDF

FP-051 / queue #64 has a bounded original raster-document composition profile. Managed static PNG/JPEG packaging is implemented; BMP/GIF/TIFF/WebP/HEIF/HEIC require an explicitly registered `IPdfRasterDocumentDecoder`. No extra file decoder, licensed codec, native runtime or binary is silently selected/downloaded. Complete per-codec/RID/licensing/frame/color and production qualification remain mandatory; the tracking requirement remains Planned.

`PdfRasterInput` requires an explicit ordered nonempty frame selection. Files remain borrowed until the operation completes. `PdfRasterDocuments` checks every optional format's availability before reading any source, captures bounded files, inspects all frame inventories and rejects missing frames/unauthorized animations before publishing a document. Repeated frames and file order remain exact. Animation decoders must return complete composited canvas frames, including disposal/blend rules; deltas are not accepted as page images. The managed PNG/JPEG profile has only frame zero. APNG control chunks reject instead of silently dropping animation.

The optional frame contract is complete unassociated RGBA8 with explicit RGB/CalRGB/three-channel ICC color, orientation and density. Providers must report/reject precision/color losses and obey the shared context before allocation; no TIFF/GIF/other real codec support is inferred from a synthetic protocol fixture. Managed PNG/JPEG use their existing exact color/ICC/Exif and explicit lossless-transcode policy, including preserved16-bit PNG/CMYK JPEG where supported. Alpha remains a separate soft mask; it is never silently flattened. PNG alpha/deinterlacing that requires conversion needs explicit `PdfImageReadOptions(allowLosslessTranscode: true)`.

Natural physical page size uses source DPI and orientation; unknown density uses explicit fallback DPI and pixel aspect. A fixed page uses contain fitting and physical margins. This profile uses unscaled MediaBoxes at most14400 points; select a fixed page when natural geometry exceeds that limit. Original image resources remain editable PDF graphics. Conversion, page/canvas assembly and writing share one operation context. Selected pages are capped at10000, per-file frame inventories at4096 and encoded files at64 MiB, further tightened by the operation policy.

`Create` returns an owned document only after all frames succeed. `Write` stages complete PDF before copying; `WriteFile` stages before atomic replacement. Failed decoding, geometry, limits, cancellation and later frames preserve prior file destinations. Caller files/providers stay open and provider leases expire.

Contract tests cover actual PNG/JPEG alpha/orientation, explicit optional frame order/DPI/color/alpha, missing codec preflight, animation authority/APNG rejection, frame-size errors, stream/file preservation, source-format mismatch, indices and limits/cancellation. Real extra codecs and independent visual/semantic/platform/package evidence remain required.
