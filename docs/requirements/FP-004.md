# FP-004: Stream filters, object streams and codecs

Status: **In progress — managed filters and object streams implemented; image providers and qualification pending**. Area: foundation. SDK production release requirement: **yes**.

## Scope

Decode and encode Flate, LZW, ASCII85, ASCIIHex, RunLength, predictors, DCT, JPX, CCITT, JBIG2 and embedded object streams through audited providers where needed.

## Implementation progress

The [managed filter contract](../pdf-filters.md) implements lossless filter chains, encoders, predictor matrices and bounded embedded-object resolution. Optional image codec integration remains in progress. Production qualification is pending.

## Dependencies

- [FP-003](FP-003.md)

## Acceptance criteria

- [ ] Honor filter chains and decode parameters.
- [ ] Enforce expanded-byte and image limits before allocation.
- [ ] Identify unsupported or damaged codecs precisely without returning corrupt content.
- [ ] Exercise strict/unsupported-content diagnostics, resource boundaries and cancellation wherever applicable.
- [ ] Keep public API, capability documentation, platform applicability and package-only examples synchronized.
- [ ] Record actual evidence from every applicable production lane; compilation alone does not qualify behavior.

## Validation

Known-answer codec corpus, predictor matrices, decompression bombs and malformed image inputs.

The common [production qualification gates](../production-quality.md) also apply. An independent reader/validator must be used where this requirement emits a standard format.

## Non-goals

- Features owned by other requirements except integration through public contracts.
- Silent fallback, unqualified support claims or changes to the approved production release scope.
