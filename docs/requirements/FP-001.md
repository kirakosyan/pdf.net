# FP-001: Public API and provider contracts

Status: **Implemented; production qualification pending**. Area: foundation. SDK production release requirement: **yes**.

## Scope

Define a small fluent facade and editable document model with provider-neutral value types, stream ownership, disposal, immutable options and explicit capabilities.

## Dependencies

None.

## Acceptance criteria

- [x] Publish an API contract with C# and VB examples.
- [x] Keep public signatures consistent across all target frameworks.
- [x] A missing optional provider produces a typed diagnostic without silently degrading output.
- [x] Exercise strict/unsupported-content diagnostics, resource boundaries and cancellation wherever applicable.
- [ ] Keep public API, capability documentation, platform applicability and package-only examples synchronized.
- [ ] Record actual evidence from every applicable production lane; compilation alone does not qualify behavior.

## Validation

Compile API contract consumers for every TFM; compare API baselines and exercise disposed objects.

The common [production qualification gates](../production-quality.md) also apply. An independent reader/validator must be used where this requirement emits a standard format.

## Implementation evidence

The [API contract](../api-contract.md), [executable examples](../../examples/README.md), [contract tests](../../tests/Fluent.Pdf.Contract.Tests) and [test procedure](../testing.md) cover the implemented scope. No standard-format output is emitted by the contract fixtures. Strict/permissive content policy and full operation budgets are FP-002 work; this layer rejects unavailable/mismatched services and bounds page/provider counts.

CI retains source reports with commit, assembly/report digests and verified runtime/architecture/assembly identities. Actual minimum Framework 4.7.2 and exact final-package consumers remain pending. The GitHub issue stays open through these qualification gaps. `implemented` does not mean `qualified`, and readiness remains false.

- Silent fallback, unqualified support claims or changes to the approved production release scope.
