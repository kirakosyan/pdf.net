# FP-075: Multilingual OCR and language models

Status: **Planned**. Area: ocr. SDK production release requirement: **yes**.

## Scope

Support explicitly provisioned language/script models, mixed languages, model selection and per-language accuracy reports for printed text.

## Dependencies

- [FP-009](FP-009.md)
- [FP-074](FP-074.md)

## Acceptance criteria

- [ ] No automatic model download or network fallback.
- [ ] Publish model versions, hashes, licenses and supported scripts.
- [ ] Confidence is reported as engine confidence rather than a correctness guarantee.
- [ ] Exercise strict/unsupported-content diagnostics, resource boundaries and cancellation wherever applicable.
- [ ] Keep public API, capability documentation, platform applicability and package-only examples synchronized.
- [ ] Record actual evidence from every applicable production lane; compilation alone does not qualify behavior.

## Validation

Labeled multilingual corpus with character/word error rates and per-language release thresholds.

The common [production qualification gates](../production-quality.md) also apply. An independent reader/validator must be used where this requirement emits a standard format.

## Non-goals

- Features owned by other requirements except integration through public contracts.
- Silent fallback, unqualified support claims or changes to the approved production release scope.

## Evidence lineage

WN01, ENH. See the [research report](../research.md) for source classes, observation limits and the distinction between declared API and verified runtime behavior.
