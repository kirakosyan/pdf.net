# FP-011: Page canvas and geometry

Status: **Planned**. Area: composition. SDK production release requirement: **yes**.

## Scope

Create pages and place text, images and paths using explicit units, transformations, page boxes, rotation, z-order, margins and coordinate conversions.

## Dependencies

- [FP-005](FP-005.md)
- [FP-008](FP-008.md)
- [FP-010](FP-010.md)

## Acceptance criteria

- [ ] MediaBox, CropBox, BleedBox, TrimBox and ArtBox remain consistent.
- [ ] Transformed bounding boxes and hit tests agree.
- [ ] Inputs with nonfinite geometry fail before writing.
- [ ] Exercise strict/unsupported-content diagnostics, resource boundaries and cancellation wherever applicable.
- [ ] Keep public API, capability documentation, platform applicability and package-only examples synchronized.
- [ ] Record actual evidence from every applicable production lane; compilation alone does not qualify behavior.

## Validation

Geometric known-answer fixtures across rotations and nonzero page origins.

The common [production qualification gates](../production-quality.md) also apply. An independent reader/validator must be used where this requirement emits a standard format.

## Non-goals

- Features owned by other requirements except integration through public contracts.
- Silent fallback, unqualified support claims or changes to the approved production release scope.

## Evidence lineage

A01, B01, D02. See the [research report](../research.md) for source classes, observation limits and the distinction between declared API and verified runtime behavior.

## Implementation progress

Original managed source now supplies immutable standard boxes/rotation/UserUnit, explicit point/inch/mm/cm/pica/pixel conversions, margin frames, scoped transforms and clipping, text/vector/image placement, stable z-order, analytic path bounds and frame/path hit tests. Atomic overlay/underlay/replacement preserves source encoded streams. Source and independent development checks do not complete the mandatory runtime/package, fidelity, security or long-workload qualification.
