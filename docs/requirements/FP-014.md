# FP-014: Lists, columns and document composition

Status: **Planned**. Area: composition. SDK production release requirement: **yes**.

## Scope

Compose numbered and bulleted lists, nested list restarts, multi-column text, section breaks, footnotes, endnotes and reusable content components.

## Dependencies

- [FP-012](FP-012.md)

## Acceptance criteria

- [ ] List counters and restarts remain stable across pages.
- [ ] Footnotes remain associated with their references.
- [ ] Column reading order matches tagged and extracted output.
- [ ] Exercise strict/unsupported-content diagnostics, resource boundaries and cancellation wherever applicable.
- [ ] Keep public API, capability documentation, platform applicability and package-only examples synchronized.
- [ ] Record actual evidence from every applicable production lane; compilation alone does not qualify behavior.

## Validation

Booklet, legal-outline and multi-column fixtures with structure and raster assertions.

The common [production qualification gates](../production-quality.md) also apply. An independent reader/validator must be used where this requirement emits a standard format.

## Non-goals

- Features owned by other requirements except integration through public contracts.
- Silent fallback, unqualified support claims or changes to the approved production release scope.

## Evidence lineage

ENH, A01. See the [research report](../research.md) for source classes, observation limits and the distinction between declared API and verified runtime behavior.

## Implementation progress

Original managed source supplies stable invariant list counters/restarts, nested lists, reusable components, section parity, fixed-height column flow, associated footnotes/endnotes and real basic column structure/parent-tree output. The supported profiles and explicit errors are documented in the composition contract. Complete legal/booklet/notes/structure corpora, full accessibility semantics, actual minimum runtimes, final packages and all production gates remain mandatory.
