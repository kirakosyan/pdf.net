# FP-110: HTML element and block extraction

Status: **Planned**. Area: web. SDK production release requirement: **yes**.

## Scope

Locate and render selected HTML elements, expose rendered element rectangles and extract blocks by selector or bounded search while preserving resource context.

## Acceptance criteria

- [ ] Define coordinate spaces, viewport and selected-element clipping.
- [ ] Report missing/ambiguous selectors and dynamic-page timeout.
- [ ] Keep element capture inside the configured origin/resource policy.
- [ ] Exercise strict/unsupported-content diagnostics, resource boundaries and cancellation wherever applicable.
- [ ] Keep public API, capability documentation, platform applicability and package-only examples synchronized.
