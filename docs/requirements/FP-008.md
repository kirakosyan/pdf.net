# FP-008: Fonts, embedding, subsetting and fallback

Status: **In progress — original managed font/provider, embedding and Unicode-map source implementation; production qualification pending**. Area: composition. SDK production release requirement: **yes**.

## Scope

Support the base 14 fonts, Type 1, TrueType, OpenType/CFF, Type 3, CID/CJK, encodings, ToUnicode maps, embedding permissions, extraction and deterministic caller-provided fallback.

## Dependencies

The [font contract](../fonts.md) documents supported source profiles, explicit provider selection, subsetting, source inspection, mappings and qualification gaps.

- [FP-004](FP-004.md)
- [FP-005](FP-005.md)
- [FP-007](FP-007.md)

## Acceptance criteria

- [ ] Subset embedded fonts without missing used glyphs.
- [ ] Report missing glyphs and restricted embedding.
- [ ] Resolve fonts without depending on machine-specific search order in deterministic mode.
- [ ] Exercise strict/unsupported-content diagnostics, resource boundaries and cancellation wherever applicable.
- [ ] Keep public API, capability documentation, platform applicability and package-only examples synchronized.
- [ ] Record actual evidence from every applicable production lane; compilation alone does not qualify behavior.

## Validation

Licensed font corpus, CJK/CID mappings, extraction round trips and cross-platform glyph comparisons.

The common [production qualification gates](../production-quality.md) also apply. An independent reader/validator must be used where this requirement emits a standard format.

## Non-goals

- Features owned by other requirements except integration through public contracts.
- Silent fallback, unqualified support claims or changes to the approved production release scope.

A01, D01, WN01. See the [research report](../research.md) for source classes, observation limits and the distinction between declared API and verified runtime behavior.
