# FP-052: SVG import and vector export

Status: **Planned**. Area: conversion. SDK production release requirement: **yes**.

## Scope

Import SVG to PDF with bounded external resources and export PDF pages or selected graphics as SVG while retaining editable vectors where possible.

## Dependencies

- [FP-009](FP-009.md)
- [FP-010](FP-010.md)
- [FP-017](FP-017.md)

## Acceptance criteria

- [ ] Handle transforms, clipping, text and embedded images.
- [ ] Disclose rasterized or unsupported constructs.
- [ ] Reject script execution and unapproved resource loading.
- [ ] Exercise strict/unsupported-content diagnostics, resource boundaries and cancellation wherever applicable.
- [ ] Keep public API, capability documentation, platform applicability and package-only examples synchronized.
- [ ] Record actual evidence from every applicable production lane; compilation alone does not qualify behavior.

## Validation

SVG conformance subset, PDF-to-SVG round trips and visual/vector inspection.

The common [production qualification gates](../production-quality.md) also apply. An independent reader/validator must be used where this requirement emits a standard format.

## Non-goals

- Features owned by other requirements except integration through public contracts.
- Silent fallback, unqualified support claims or changes to the approved production release scope.

## Evidence lineage

A01, D01, B01. See the [research report](../research.md) for source classes, observation limits and the distinction between declared API and verified runtime behavior.

## Source progress

The optional [static SVG/vector source profile](../svg.md) has original bounded import/export and independently checked vector/clip round trips. Full SVG/CSS/path/paint/text/image profiles and production qualification remain mandatory; status remains Planned.
