# FP-050: Text, Markdown and structured input

Status: **Planned**. Area: conversion. SDK production release requirement: **yes**.

## Scope

Generate PDF from UTF text, Markdown, JSON-bound templates and a documented XML document schema with culture, style and resource options.

## Dependencies

- [FP-009](FP-009.md)
- [FP-012](FP-012.md)
- [FP-013](FP-013.md)
- [FP-015](FP-015.md)

## Acceptance criteria

- [ ] Markdown tables, lists, links and code preserve semantics.
- [ ] XML external entities and unsafe resource references are disabled.
- [ ] Unknown schema fields are diagnostic and strict-mode failures.
- [ ] Exercise strict/unsupported-content diagnostics, resource boundaries and cancellation wherever applicable.
- [ ] Keep public API, capability documentation, platform applicability and package-only examples synchronized.
- [ ] Record actual evidence from every applicable production lane; compilation alone does not qualify behavior.

## Validation

Source-to-PDF text/structure goldens; malformed input and large-data boundary tests.

The common [production qualification gates](../production-quality.md) also apply. An independent reader/validator must be used where this requirement emits a standard format.

## Non-goals

- Features owned by other requirements except integration through public contracts.
- Silent fallback, unqualified support claims or changes to the approved production release scope.

## Evidence lineage

A01, B01, D01, D02. See the [research report](../research.md) for source classes, observation limits and the distinction between declared API and verified runtime behavior.

## Source implementation progress

The bounded [input conversion source profile](../input-conversion.md) provides original Unicode/Markdown/JSON/XML parsers, explicit culture/styles/resources, scalar binding, nested passive URI annotations and shared-budget atomic generation. Full requirement scope and every production gate remain mandatory. Status stays planned until reviewed implementation and qualification justify reconciliation after merge.
