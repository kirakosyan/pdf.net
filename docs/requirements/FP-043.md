# FP-043: Cross-platform printing

Status: **Planned**. Area: rendering. SDK production release requirement: **yes**.

## Scope

Provide Windows print-system and Linux/macOS CUPS/IPP adapters for printer selection, copies, duplex, ranges, scaling, N-up and spool status.

## Dependencies

- [FP-016](FP-016.md)
- [FP-040](FP-040.md)
- [FP-041](FP-041.md)

## Acceptance criteria

- [ ] No implicit printer selection or print on document open.
- [ ] Return actionable spool and permissions errors.
- [ ] Document headless and interactive applicability per platform.
- [ ] Exercise strict/unsupported-content diagnostics, resource boundaries and cancellation wherever applicable.
- [ ] Keep public API, capability documentation, platform applicability and package-only examples synchronized.
- [ ] Record actual evidence from every applicable production lane; compilation alone does not qualify behavior.

## Validation

Virtual-printer integration plus controlled real-printer qualification; print-job cleanup and cancellation.

The common [production qualification gates](../production-quality.md) also apply. An independent reader/validator must be used where this requirement emits a standard format.

## Non-goals

- Features owned by other requirements except integration through public contracts.
- Silent fallback, unqualified support claims or changes to the approved production release scope.

## Evidence lineage

A01, B01, D01, D02. See the [research report](../research.md) for source classes, observation limits and the distinction between declared API and verified runtime behavior.

## Source progress

An original bounded [printing profile](../printing.md) implements explicit orchestration and IPP 2.0 protocol operations. Complete native Windows adapters, configured transport/printer integration and production evidence remain mandatory; status remains Planned.
