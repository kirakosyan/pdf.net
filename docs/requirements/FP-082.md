# FP-082: Application integrations and viewer controls

Status: **Planned**. Area: integration. SDK production release requirement: **yes**.

## Scope

Provide optional ASP.NET, WinForms, WPF and cross-platform application samples or controls using shared viewing primitives; keep the standalone Reader product independent.

## Dependencies

- [FP-001](FP-001.md)
- [FP-042](FP-042.md)
- [FP-043](FP-043.md)
- [FP-048](FP-048.md)

## Acceptance criteria

- [ ] Core remains usable without UI assemblies.
- [ ] Each control declares exact OS/runtime applicability.
- [ ] Keyboard, accessibility and cancellation contracts are documented.
- [ ] Exercise strict/unsupported-content diagnostics, resource boundaries and cancellation wherever applicable.
- [ ] Keep public API, capability documentation, platform applicability and package-only examples synchronized.
- [ ] Record actual evidence from every applicable production lane; compilation alone does not qualify behavior.

## Validation

Minimal consumer applications and accessibility integration checks for each shipped control.

The common [production qualification gates](../production-quality.md) also apply. An independent reader/validator must be used where this requirement emits a standard format.

## Non-goals

- Features owned by other requirements except integration through public contracts.
- Silent fallback, unqualified support claims or changes to the approved production release scope.

## Evidence lineage

D01, D02, B01, ENH. See the [research report](../research.md) for source classes, observation limits and the distinction between declared API and verified runtime behavior.
