# FP-085: Native provider deployment and isolation

Status: **Implemented; production qualification pending**. Area: production. SDK production release requirement: **yes**.

## Scope

Define RID-specific packaging/provisioning, exact engine versions, hashes, dependency probes, sandbox boundaries, safe library search and crash recovery.

## Implementation progress

The [native deployment contract](../native-deployment.md) covers immutable offline assets and the optional isolated worker host. The original C host applies platform restrictions before dynamic loading, probes actual ABI/version/exports/dependencies, bounds transport and native resources, supervises cancellation/crashes and preserves atomic output. The [source evidence summary](../evidence/FP-085-source.json) records 182 cases across 20 execution lanes on six native hosts, including current Framework x86/x64, with zero failures/skips. Production qualification, reviewed engine assets and exact-package evidence remain mandatory and incomplete.

## Acceptance criteria

- [x] No runtime binary download or PATH-based unsafe loading by default.
- [x] Providers report architecture, ABI and missing dependency details.
- [x] Native crash/resource limits cannot corrupt the caller's persisted output.
- [x] Exercise strict/unsupported-content diagnostics, resource boundaries and cancellation wherever applicable.
- [ ] Keep public API, capability documentation, platform applicability and package-only examples synchronized.
- [ ] Record actual evidence from every applicable production lane; compilation alone does not qualify behavior.

## Validation

Windows/Linux/macOS x64/ARM64 deployment probes, wrong ABI, read-only filesystem and crash injection.

The common [production qualification gates](../production-quality.md) also apply. An independent reader/validator must be used where this requirement emits a standard format.

## Non-goals

- Features owned by other requirements except integration through public contracts.
- Silent fallback, unqualified support claims or changes to the approved production release scope.
