# FP-084: Developer documentation and executable examples

Status: **Planned**. Area: integration. SDK production release requirement: **yes**.

## Scope

Publish API reference, capability matrices, offline deployment, diagnostics, security, samples and task-focused recipes synchronized with package versions.

## Dependencies

- [FP-001](FP-001.md)
- [FP-065](FP-065.md)
- [FP-071](FP-071.md)

## Acceptance criteria

- [ ] Every advertised code sample builds and runs against the published package.
- [ ] Clearly identify optional providers and platform prerequisites.
- [ ] Document lossy conversions and unsupported behavior at the API boundary.
- [ ] Exercise strict/unsupported-content diagnostics, resource boundaries and cancellation wherever applicable.
- [ ] Keep public API, capability documentation, platform applicability and package-only examples synchronized.
- [ ] Record actual evidence from every applicable production lane; compilation alone does not qualify behavior.

## Validation

Documentation snippet compilation, clean sample consumers and broken-link checks.

The common [production qualification gates](../production-quality.md) also apply. An independent reader/validator must be used where this requirement emits a standard format.

## Non-goals

- Features owned by other requirements except integration through public contracts.
- Silent fallback, unqualified support claims or changes to the approved production release scope.

## Evidence lineage

D01, D02, ENH. See the [research report](../research.md) for source classes, observation limits and the distinction between declared API and verified runtime behavior.
