# FP-029: Document comparison and change reports

Status: **Planned**. Area: extraction. SDK production release requirement: **yes**.

## Scope

Compare text, structure, geometry and rendered appearance with configurable tolerances and annotated PDF, JSON and HTML reports.

## Dependencies

- [FP-025](FP-025.md)
- [FP-027](FP-027.md)
- [FP-040](FP-040.md)

## Acceptance criteria

- [ ] Separate textual, visual and metadata differences.
- [ ] Ignore configured volatile fields reproducibly.
- [ ] Keep page/object provenance for each change.
- [ ] Exercise strict/unsupported-content diagnostics, resource boundaries and cancellation wherever applicable.
- [ ] Keep public API, capability documentation, platform applicability and package-only examples synchronized.
- [ ] Record actual evidence from every applicable production lane; compilation alone does not qualify behavior.

## Validation

Labeled changed-document corpus; precision/recall, rotated pages and unchanged-document zero-diff tests.

The common [production qualification gates](../production-quality.md) also apply. An independent reader/validator must be used where this requirement emits a standard format.

## Non-goals

- Features owned by other requirements except integration through public contracts.
- Silent fallback, unqualified support claims or changes to the approved production release scope.
