# FP-111: Hyphenation and advanced text-fit controls

Status: **Planned**. Area: composition. SDK production release requirement: **yes**.

## Scope

Provide language-aware hyphenation dictionaries, custom rules, paragraph line breaking, overlap policy, fit-to-paper scaling and explicit CSS page-rule precedence.

## Dependencies

- [FP-009](FP-009.md)
- [FP-012](FP-012.md)
- [FP-047](FP-047.md)

## Acceptance criteria

- [ ] Pin dictionary provenance/version and allow offline provisioning.
- [ ] Hyphenation preserves logical searchable text.
- [ ] Overflow never silently clips or shrinks beyond caller limits.
- [ ] Exercise strict/unsupported-content diagnostics, resource boundaries and cancellation wherever applicable.
- [ ] Keep public API, capability documentation, platform applicability and package-only examples synchronized.
- [ ] Record actual evidence from every applicable production lane; compilation alone does not qualify behavior.

## Validation

Multilingual word-break goldens, custom dictionary tests and paper-fit/overlap boundary cases.

The common [production qualification gates](../production-quality.md) also apply. An independent reader/validator must be used where this requirement emits a standard format.

## Non-goals

- Features owned by other requirements except integration through public contracts.
- Silent fallback, unqualified support claims or changes to the approved production release scope.

## Evidence lineage

B01, ENH. See the [research report](../research.md) for source classes, observation limits and the distinction between declared API and verified runtime behavior.
