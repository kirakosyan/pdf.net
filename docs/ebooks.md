# Ebook conversion source profile

`PdfEbooks.WriteEpub` writes an original EPUB3 package with an uncompressed first `mimetype`, container, explicit identifier/title/language/UTC modification metadata, unique manifest IDs/paths, ordered spine and XHTML navigation. Page selection is explicit (1–512 existing pages, including duplicates). `PdfEbookOptions` selects fixed-raster or reflow-text layout and explicit page progression. Identifiers and timestamps come from the caller; there is no ambient clock/random identity. Publication language uses a bounded modern BCP47 syntax profile.

Fixed raster output requires an explicit renderer and produces embedded PNG images and XHTML viewports. `Ebook.RasterPage` discloses each rasterized page and the absence of editable objects, navigation and accessibility semantics. Viewports round physical dimensions to positive CSS pixels at 96 CSS pixels per inch; the PNG rendering DPI remains caller-selected. Raster import/fixed-layout reconstruction, embedded fonts and complete reader/RTL/accessibility fidelity remain pending.

Reflow output uses passive managed text extraction, escaped XHTML `pre` blocks and declared `Ebook.TextReconstruction` losses for original layout, graphics, fonts, CSS/visibility, navigation, metadata and semantics. Strict policy rejects; permissive policy must be explicit. It does not infer original headings, tables or reading-order semantics.

`ImportReflowText` reads a single-root EPUB3 package in spine order, accepting the documented text-only XHTML element matrix with the fixed pre-wrap stylesheet. Ordinary text collapses XHTML whitespace, `br` retains line breaks, and structural paragraph boundaries remain separate from source blank lines; `pre` retains literal whitespace. Caller typography, shaping providers and flow geometry are explicit. Reconstruction losses require permissive policy. Fixed/nonlinear layouts, images/media, unknown styles/elements/attributes, scripts/actions, external resource targets and ambiguous manifest identities reject. Empty text cannot produce a substitute document. Publication metadata and source navigation are not copied into the reconstructed PDF. Encrypted/obfuscated resource catalogs report `Ebook.EncryptedResources`; there is no DRM circumvention or implicit font deobfuscation.

`WriteMobiSource` emits documented UTF8 text-only MobiXML source: literal title/identifier, escaped `pre` blocks and namespace-qualified `mbp:pagebreak` markers. It requires the same explicit loss authority. No Mobi/KF8 binary compilation, DRM handling, fixed-layout fidelity or compatibility with every book compiler is claimed.

The package boundary preflights ZIP paths, extents, encryption/methods and expansion before archive allocation; decompression checks lengths/CRC. Local/central headers and data descriptors must agree, local extents cannot overlap, and ZIP64/alternate Unicode path identities reject before archive allocation. XML has no DTD, stylesheet/entity resolver or action execution. Parsing, extraction, raster encoding, layout and output share one bounded operation context with cancellation/deadlines. Stored MIME entries are written directly, independently of runtime ZIP compression behavior. Writes stage before caller streams; input/output/providers remain caller-owned. Formats adds no runtime JVM/browser/native dependency to the SDK and targets all four managed frameworks.

Nine source tests cover spine/page ordering, metadata, literal markup, MobiXML breaks, loss authority, stream ownership, encrypted resources, scripts, external references, entities, ZIP expansion bombs, provider availability, object budgets and cancellation. Explicitly provisioned EPUBCheck 5.3.0 independently validates controlled fixed/reflow packages with zero errors/warnings. Its exact JAR inventory, actual Java identity and artifact/report hashes are retained by the development check scripts. XML/image readers independently inspect data and MobiXML syntax. These fixtures do not qualify complete book coverage or final packages. FP-057 remains Planned with its full mandatory scope intact.
