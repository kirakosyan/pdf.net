# Explicit image cleanup and blank-page evidence

FP-103 has a managed source checkpoint. Full corpus, OCR accuracy, minimum-runtime, RID and exact-package qualification remain mandatory. No candidate package or public release is authorized.

`PdfImageCleanup.Process` accepts an immutable `PdfOcrRaster`; it discovers no decoder, renderer, native engine or model. The default returns the exact original instance, including row padding and its capture report. `Original` remains available after every transformation. This is source preservation, not a claim that lossy pixels can be reconstructed from the processed image alone.

Transforms require `allowLossy: true` and a permissive operation policy. Strict mode rejects with `Cleanup.ExplicitLoss`. Each successful transform records a fidelity-loss diagnostic. Color-to-gray conversion uses the existing integer `(77R + 150G + 29B + 128) >> 8` device-luma profile; it is not ICC conversion. Median filtering uses replicated edges and the middle of nine Gray8 values. Threshold maps values below the explicit byte threshold to zero and all others to255. Median/threshold on a color raster require explicit grayscale authority. These operations precede crop and resize; therefore a boundary median can sample pixels later cropped away.

Border removal means explicit counts of source rows/columns on each side. Automatic border inference is not implemented. A crop must retain a nonempty rectangle. Resampling selects the nearest source pixel by integer pixel-center mapping, independently per axis; it can alias and is not an antialiased photographic reduction filter. RGB/BGRA geometry-only transformations retain channel order and alpha exactly. Gray conversion and blank analysis reject nonopaque BGRA rather than guessing a matte. Output dimensions are explicit. `OutputToOriginal` maps output pixel edges back into original coordinates; `Dpi` remains the original nominal OCR hint and must not replace this geometry after resize.

Optional blank analysis examines every active pixel, excluding row padding, against the caller's opaque RGB background. A pixel is foreground when its largest absolute channel difference exceeds `ChannelTolerance`. `IsBlank` compares the measured foreground fraction to `MaximumForegroundFraction`. `Confidence` is exactly one minus foreground fraction. It is an uncalibrated background statistic, not a probability that a page lacks meaningful content. A single faint mark can be important even when the configured threshold accepts it. No page is deleted, cropped or rewritten by a blank classification.

`Before` always measures the full original before destructive operations. `After` separately measures the processed output; unchanged output reuses the same observation. This exposes cases where thresholding or cropping removes meaningful content. The captured parameters, measured counts, inverse matrix and stable diagnostics accompany each result. The seven original labeled fixtures include white, near-white, isolated noise, faint text, borders, colored backgrounds and a resampling gradient. Independent scalar checks compare exact source/output pixels, geometry, counts, confidence and same-geometry mean absolute error. They do not establish real-world classification accuracy or improved OCR.

All stages share one operation context. Pixel, expanded-byte and object budgets apply before allocation; each new raster stage is bounded to64MiB. `MaximumPixelVisits` covers analysis, existing gray/filter stages and resampling. Cancellation and the cooperative deadline are checked during loops. Original arrays are immutable and independent jobs share no mutable cleanup state. No global image library or platform graphics dependency is introduced.

C# and VB source consumers demonstrate explicit options and permissive processing. Existing [scan processing](scan-processing.md) supplies orientation, deskew, dewarp and OCR integration, with its own retained limitations. Broader color/alpha/automatic-border profiles, labeled real-scan false-positive rates, before/after OCR CER/WER, actual Framework4.7.2 execution for this source, all mandatory hosts and final-package consumers remain pending.
