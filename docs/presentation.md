# Outlines, labels and presentation

FP-021 has an original managed source implementation across the four core target frameworks. `PdfPresentation` stages a new document for each edit. Input snapshots stay detached and immutable. It never runs an imported action, animation, print job or viewer UI. Layout/mode/preferences and transition dictionaries are requests for a later conforming viewer, which may ignore them.

`PdfBookmark` captures a Unicode title, a local `PdfDestination` or passive `PdfAction`, expansion state, bold/italic flags, optional device RGB color and ordered immutable children. `WithChildren` is convenient for both C# and VB. `SetOutlines` replaces the tree; an empty batch clears it. Actual indirect Parent/Prev/Next/First/Last links and signed visible-descendant counts are written. The batch has a 100,000-node ceiling in addition to shared object/byte/depth/time budgets. `Inspect` preserves each source dictionary and identity, resolves local named/explicit destinations, detects repeated/cyclic outline nodes and inconsistent links, and reports unsupported settings/counts. Page moves retain targets by identity; organization resolves and remaps them through merge/extraction. Omitted targets still use the explicit organization policy and loss reporting. Replacing a tree does not erase old unreferenced objects.

`SetPageLabels` uses the existing immutable `PdfPageNumbering` contract: zero-based physical starts, positive restart counters, Unicode prefixes and decimal, Roman, repeated-letter or prefix-only styles. Starts must identify existing pages. Null clears explicit labels. Inspection traverses bounded sorted number trees, rejects cycles/duplicate/out-of-range starts, and retains raw range dictionaries. `Numbering` is null, with a diagnostic, for unsupported styles or ranges outside the formatter profile (4,096 ranges, 128-character prefixes, Roman values through 3,999, repeated-letter values through 3,328). Raw source ranges remain inspectable and survive unrelated edits. Page organization carries each selected page's label; ordinary label ranges refer to physical indices.

`SetView` sets standard SinglePage/OneColumn/two-column/two-page layouts and UseNone/UseOutlines/UseThumbs/FullScreen/UseOC/UseAttachments modes. Null preserves an existing layout/mode. `SetInitialView` sets a standard local OpenAction destination array; null clears it. This is separate from the explicit action factory/policy used for authored action dictionaries.

`SetViewerPreferences` accepts a detached dictionary of standard keys with validated PDF value types. It patches by default, preserving unrelated source preferences; `replace: true` explicitly replaces the whole preference dictionary, and an empty replacement clears it. Supported keys include HideToolbar, HideMenubar, HideWindowUI, FitWindow, CenterWindow, DisplayDocTitle, NonFullScreenPageMode, Direction, ViewArea/ViewClip/PrintArea/PrintClip, PrintScaling, Duplex, PickTrayByPDFSize, PrintPageRange and NumCopies. **PrintPageRange contains one-based inclusive page pairs**, unlike zero-based page-label starts and SDK page indices. Positive NumCopies is bounded at 100,000; actual printer/viewer behavior is outside this source profile. Enforce supports PrintScaling with PrintScaling=None and negotiates PDF 2.0. Unknown supplied keys or malformed values fail. Inspection retains unknown source keys/values with warnings even in strict mode, because it performs no lossy conversion. A warning never grants permission to execute active content.

`PdfPageTransition` supports the twelve standard styles. The public Replace enum emits the standard `/R` name. Split/Blinds dimensions, Split/Box/Fly motion, style-specific direction angles, Fly nondirectional `None`, finite nonnegative Fly scale and the rectangular flag are validated. Angles 90/180 apply only to Wipe; Glitter additionally permits 315. Transition duration is finite in 0..86,400 seconds; it is ignored by the standard replacement effect. `SetPageTransition` writes a transition and optional page display duration (Dur), also finite in 0..86,400. Null settings remove the corresponding source keys. Inspection retains unknown transition settings and reports diagnostics. This does not implement rendering or transition playback.

All operations use shared cancellation, budgets, scoped depth and stable diagnostics. Source signatures require explicit invalidation permission for rewrites. Borrowed stream ownership and atomic path saving retain the common writer contract. C#/VB `WritePresentationPdf` emits nested bookmarks, restarted labels, a viewer mode and a passive transition. Tests include finite deep trees, cycles, count/link correctness, Unicode/style, page remapping, every transition, parameter errors, unknown-setting preservation, label formatting/number trees, preferences/version negotiation, cancellation and resource failure. Full viewer/standards/corpus validation, actual minimum Framework runtimes, exact final package consumers and every production gate remain mandatory. NuGet packing/publication remains blocked.
