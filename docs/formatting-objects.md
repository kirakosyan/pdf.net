# XSL-FO and XML transform source profile

`PdfFormattingObjects.Import` implements a closed passive FO profile with one simple page master, one page sequence and one body flow. Explicit pt/mm/cm/in page sizes and uniform margins determine geometry. Blocks accept literal collapsed text, physical font size and before/after spacing; fonts/shaping remain caller supplied. Fixed-width table columns, header/body rows and text cells use the shared paginator. Unknown elements/properties, graphics, resource URIs, external fonts, regions or extensions always reject. No ambient resolver, native process or general stylesheet engine runs.

`Transform` accepts a closed declarative XSLT1.0 data profile: a single `/` template, literal supported FO elements, `xsl:text`, `xsl:value-of` and `xsl:for-each`. Selectors are finite literal unqualified child paths or the current element, not general XPath. Values become text nodes. Attribute value templates, scripts, functions, DTD/entities, includes/imports, document retrieval, recursive template application and all other instructions reject. Every branch is validated before evaluation, including loops selecting no data. This is a documented data subset, not complete XSLT or FO support.

Capture, XML preflight, transform expansion, formatting, shaping, pagination and document creation use one operation context. XML is bounded to8 MiB, transform nesting128, columns1024, rows100000 and output pages at the explicit caller limit. Expansion/object/depth budgets are charged before new output nodes/strings; cancellation and deadlines remain cooperative across phases. Borrowed streams/providers remain caller-owned.

Full standards-oriented optional adapter, page-master selection, regions, spans, inline formatting/resources, XSLT language coverage, malicious stylesheet and page-master/table corpus plus supported-host/package qualification remain mandatory for FP-062, which stays Planned. Controlled output is inspected with an independent PDF reader; source fixtures do not qualify complete standards support.
