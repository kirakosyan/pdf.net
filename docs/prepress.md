# PDF/X exact-byte source gate

`PdfProfileOptions` selects an exact PDF/X-1a:2001/2003, PDF/X-3:2002/2003 or PDF/X-4:2010 edition, a complete explicit RGB/CMYK ICC output space and a literal print condition. PDF/X-1a requires CMYK. No output profile/font/engine is discovered implicitly; external-output-intent variants are not advertised.

`PdfProfileConversions.Convert` requires an explicit complete producer and a separately identified independent complete validator before source capture. It stages at most64 MiB each of input and candidate, reparses a nonempty PDF, requires exact page geometry/count retention and checks that the candidate embeds the requested ICC bytes with the exact GTS_PDFX output condition. The independent result must match the exact profile, SHA256 of candidate bytes and a request digest covering settings/ICC. Incomplete, failed, stale or mismatched results cannot expose output. `Validate` makes the same exact-byte/settings checks without modifying input. Fixtures implementing these contracts do not implement or qualify the standards.

Producer/validator work and all capture/parse/filter/hash/write phases use one context. Provider leases expire on return; exceptions redact backend details while preserving latched budgets, losses and cancellation. Providers must report every transparency-flattening, color-conversion or unsupported-content loss; strict policy rejects it. Signatures require explicit invalidation authority and declared loss. Caller streams/providers remain caller-owned and input/output must be distinct.

The managed gate is not a complete producer, prepress repair engine or independent standard validator. No metadata flag is treated as compliance. Complete PDF/X conversion/repair, color/spot/separation/transparency/font/bleed corpus, actual independent full-profile validators and supported-host/package production qualification remain mandatory for FP-068, which stays Planned. Current contract fixtures exercise binding and publication boundaries only, with names explicitly identifying them as fixtures.
