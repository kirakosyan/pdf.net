# Bounded HTML element capture

FP-110/#110 remains planned and unqualified. The optional Html assembly now exposes `ChromiumHtmlRenderer.Capture`, `HtmlElementRequest` and detached `HtmlElementCapture`. It reuses whole-document rendering's exact engine/version check, private browser context, GET interception, per-job managed resource/authentication session, finite readiness and mandatory operation context. The managed core acquires no browser or platform dependency.

Select exactly one main-document light-DOM element by CSS selector, or by ordinal literal substring within individual text nodes. Literal matches select the unique parent element; direct script/style/noscript/template text is excluded. This is a source text-node search, not a semantic/visible-text or shadow-DOM search. The traversal rejects missing/ambiguous matches, invalid selectors and an exhausted node/text budget. It visits at most the caller's 1–100,000 element/text nodes; individual searched text nodes are at most 65,536 characters and total searched text at most 1 Mi characters. There is no silent first-match selection.

`ViewportBounds` is the transformed border bounding rectangle in CSS viewport pixels, with top-left origin and downward-positive Y. `DocumentBounds` adds the observed scroll offset. `CaptureBounds` rounds outward to integer pixels and clips to the document's content surface. Device scale and visual viewport scale must both equal one; PNG dimensions equal the capture extent. A rotated border produces an axis-aligned bounding rectangle. The capture is the painted page in that rectangle: ancestor overflow clips its descendants, other overlapping content remains visible, and shadows/descendants outside the border box are excluded. It neither isolates, reparents, scrolls nor reflows the element. Offscreen capture retains the original viewport and viewport-relative CSS sizing.

Pixels are charged before screenshot allocation, with a native-pixel reservation as well as the supervised host's hard memory limit. Maximum dimensions are 16,384 each, caller area is at most 64 Mi pixels, and encoded PNG output is at most 8 MiB (also subject to transport and cumulative operation budgets). The result passes the ordinary bounded managed PNG CRC/chunk/data reader before exposure. `OpenPng` creates a fresh immutable caller-owned stream.

Optional `maximumMarkupCharacters` defaults to zero. Explicit extraction uses bounded markup admission and returns original active `outerHTML` plus the final private `BaseAddress`; these are private untrusted source, not sanitized HTML or a self-contained resource bundle. Never execute extracted markup or log its resource addresses/credentials. External resources still require the existing [explicit origin/IP/authentication policy](html-resources.md).

Selection records the actual node and document in an isolated world. A mutation observer and a second identity/geometry/viewport observation reject changed documents/nodes or intervening DOM mutation with `Html.ElementChanged`. No result or partial PNG is exposed, and the SDK does not retry an unstable page. This is a conservative before/after guard, not an atomic freeze of all visual state: CSS animation, canvas/video, compositor-only changes and continuous application updates require additional qualified profiles. Child frames, workers and replacement navigation retain the ordinary renderer's explicit rejection behavior. Readiness timeout and cancellation include the same shared host cleanup boundary.

Compiled C# and VB consumers call `CaptureHtmlElement(renderer, source, selector)`. Source tests cover selection errors, pixel/output admission, PNG validation, private diagnostics, cancellation, immutable output and DOM change. The [private container source host](browser-container.md) supplies finite actual-browser fixtures for nested transforms/rotation, overflow, offscreen `vh`, literal markup, deterministic node replacement and authenticated managed main/CSS resources. Authentication is an original in-memory managed transport fixture; it does not qualify TLS or an actual remote identity service. Independent readers check exact PNG pixels and PDF text.
