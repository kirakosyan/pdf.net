# OFD raster-page source profile

`PdfOfd.WriteRasterPages` writes an original OFD1.0 package in the2016 namespace with explicit document ID/title/calendar date, ordered fixed pages, physical mm boxes and document-owned PNG resources. Each page has one body-layer image with an explicit unit-image transform. Raster appearance is explicit; editable text/fonts/vectors, source annotations and signature validity are not reconstructed. Caller-selected raster policy and renderer determine samples. The first source page supplies the common default page area; every page also declares its own authoritative geometry.

`ImportRasterPages` accepts this closed single-document raster profile, preserves page order and physical geometry, and returns original literal metadata through `out PdfOfdIdentity`. Source identity is separate from PDF metadata. Unit IDs must be unique and within MaxUnitID; page/resources must belong to the owning document and every referenced part must exist. Unknown extensions, unused parts/resources, fonts/text/vectors/effects/actions, malformed geometry and partial image transforms reject. Signed OFD packages report `Ofd.SignatureUnsupported`: converting bytes cannot assert preservation of source signature validity.

The common ZIP/XML boundary rejects traversal, external/ambiguous paths, CRC/header/descriptor conflicts, DTD/entities and excessive expansion. Input/output package bounds are64 MiB, XML/part bounds are explicit, page selection is1–512 and every capture/decode/layout/write phase uses the same operation context. Output stages before caller writes; streams/providers remain caller-owned. No native/GUI/fonts/network or runtime dependency discovery occurs in SDK processing.

Independent development-only OFD reader checks use explicitly pinned local artifacts, with every JAR digest recorded. Controlled PNG/page fixtures establish only the recorded geometry/order/pixels. Full OFD text/font/vector/metadata/extension/signature preservation and verification plus independent corpus, OS/host and production qualification remain mandatory for FP-063, which stays Planned.
