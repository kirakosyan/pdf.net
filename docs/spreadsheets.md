# Spreadsheet data source profile

`Fluent.Pdf.Formats.PdfSpreadsheets` reads one explicitly named data sheet from UTF8 RFC4180 CSV, SpreadsheetML, XLSX or ODS and writes a single data sheet in those formats. `FromTable` retains previously inferred PDF cells, spans, explicit-culture decimal types, source pages and bounds. `WriteProvenance` emits a separate passive XML ledger; spreadsheet output does not invent formulas. `ImportData` reconstructs an explicit zero-based range as a paginated table with caller fonts, shaping provider and layout. A range crossing a merge rejects.

The immutable grid accepts at most 100000 positions and 1024 columns. Names are explicit, valid spreadsheet names of at most 31 characters. Scalars are Unicode text, invariant decimals, booleans or ISO calendar dates. CSV never guesses types. Date serials/styles, currency display and source print styling are not inferred. Trailing grid dimensions are preserved in typed containers. Merges must be rectangular, in bounds and non-overlapping. Interior cells under a merge reject rather than silently disappearing.

Formula cells require an explicitly typed cached value. `SourceFormula` is observational provenance; writers emit cached scalar values, never formula records. Literal `=SUM(...)` remains a string in typed containers. CSV rejects merges and formula-like text (including leading whitespace followed by `=`, `+`, `-`, `@`) because it cannot preserve literal typing in spreadsheet applications. No apostrophe or other invisible value mutation occurs. Explicit negative numeric cells remain numbers on typed export and ordinary CSV text on CSV read.

The package boundary preflights classic single-disk ZIP headers before archive allocation: at most 4096 canonical ASCII part names, 64 MiB captured input/total declared expansion, 16 MiB per part, no encryption, ZIP64, traversal, ambiguous duplicate identities or external references. Decompression additionally checks exact lengths and independent CRC32. XML forbids DTDs, external resolvers and processing instructions; depth, nodes and expanded memory share the operation context with parsing and reconstruction. Streams remain caller-owned; writes stage all bytes before copying. Cancellation and latched limits propagate.

Binary XLS reports `Spreadsheet.AdapterUnavailable` before reading. XLSX macros, connections and external workbook links reject. ODS structured inline text/repetitions outside the bounded matrix reject. No formula evaluation, external links, chart reconstruction, original worksheet pagination, print-area fidelity, binary XLS engine or full-format qualification is claimed. All remain mandatory for FP-054, which stays Planned. The data profile runs on all four managed targets without Office/COM/browser dependencies.

`SpreadsheetTests` exercise typed round trips, merges, cached formulas, RFC4180 fields, source coordinates, range selection, unavailable adapters, unsafe packages, budgets and cancellation. Controlled output is independently opened with a spreadsheet reader; those fixtures do not qualify full spreadsheet coverage or packages.
