# HTML export source profile

`PdfHtmlExport.Write` and `WriteFile` support explicit `FixedRaster` and `InferredText` modes with a literal title/language, selected pages in exact caller order, and finite rendering/extraction policies. Output is UTF8 HTML5 with escaped source text, unique per-occurrence page IDs and source-page provenance. There are no source scripts, active links, forms, external fonts, asset fetches or source CSS. The generated CSP denies all resources except embedded data images and the fixed internal stylesheet, with `base-uri` and `form-action` disabled.

Fixed raster mode requires a caller-installed renderer. Whole selected CropBox appearances become self-contained PNG images at explicit DPI, positioned at their physical page dimensions. `HtmlExport.RasterPage` reports every rasterized page and explicitly discloses the absence of reconstructed text/navigation/accessibility semantics. This named mode is an explicit raster choice, without an automatic fallback. Generic image alt text does not establish accessible document equivalence.

Inferred text mode uses passive managed text extraction under the same operation context. Each page becomes an escaped `pre` block with wrapping CSS. It reports `HtmlExport.InferredText` as a fidelity loss for every page: original geometry, fonts, graphics, navigation and semantic structure are not retained. Strict policy rejects; callers must explicitly select permissive policy to obtain this profile. No headings, tables or document roles are invented from appearance. Unrepresentable XML/HTML text characters reject.

Selection accepts 1–512 existing pages, including duplicates. Each embedded image is at most 16 MiB; complete output stages within a 64 MiB sink before copying to caller streams or atomic file replacement. Raster capture, encoding, extraction and markup allocation share limits, deadlines and cancellation. Caller streams/providers remain caller-owned. No browser/native/GUI dependency is introduced into Formats or the core.

`HtmlExportTests` cover page order/physical dimensions, escaping, CSP/offline image identity, explicit loss policy, missing renderers, budgets and mid-render cancellation without partial publication. An independent HTML parser/image reader checks controlled output; actual browser render comparison and accessibility review remain pending. Source semantic reconstruction, original links/structure, embedded font/CSS reconstruction, controlled external asset callbacks and complete production/package qualification remain mandatory for FP-056. Its status stays Planned.
