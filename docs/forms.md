# AcroForm fields and widgets

FP-036 has an original managed source profile on net472, netstandard2.0, net8.0 and net10.0. `PdfForms.Inspect` captures the passive field tree, inherited values/defaults/flags/default appearance properties, logical qualified names, terminal representations and exact widget/page identities. It does not execute calculations, actions or XFA. XFA remains inspectable with a diagnostic; mutations require a separate synchronization/removal profile.

`Add` creates text, checkbox, radio, combo/list choice, push-button and unsigned signature fields with private caller-supplied Form appearances. Hierarchical names create missing containers. Named siblings must be distinct; existing valid unnamed terminal representations can share a common named ancestor only with matching type, values, defaults and flags. `AddWidget` extends an existing logical field without inventing a duplicate name. Source merged field/widgets and multiple legacy terminal representations require an explicit consolidation profile before adding widgets.

State buttons require Off/on appearances and matching export names. Radio exports are distinct unless RadiosInUnison is explicit; shared checkbox widgets have the same export. Current values determine each widget's AS. Choice exports are unique, optional sorting is ordinal by display text, and selected V/I entries follow option order. Text MaxLen is checked in Unicode scalars. Kind-specific flag combinations reject invalid authoring. Unsigned signature authoring sets SigFlags' presence bit; it does not create a signature.

Variable text fields require an explicit editing font and DA/DR in addition to their authored appearance. `CreateTextAppearance` embeds existing shaped Unicode runs in a private Form and rejects conservative text overflow. Complex script shaping needs the explicit shaping provider. Authoring a value does not infer its appearance or a password mask: the caller supplies matching presentation data. Editing-font glyph encoding/coverage remains the explicitly supplied resource; arbitrary later viewer edits, full interactive multilingual regeneration and every viewer font substitution profile remain mandatory work. The supplied font's full program alone does not establish an unrestricted PDF character encoding.

`Rename` changes the nearest named ancestor, preserving indirect identities and descendant relationships. Scripts and form actions may contain opaque name references: renaming rejects unless the caller explicitly retains those references, with a retained-reference diagnostic. No script is rewritten or executed. `SetCalculationAction` uses the explicit navigation action policy and synchronizes CO when adding/removing a passive calculation. `SetCalculationOrder` validates passive CO terminal references and preserves calculation action dictionaries; every field with a calculation action must remain in CO.

`SetCommonFlags` changes ReadOnly/Required/NoExport while preserving kind-specific source flags. `EditWidget` replaces normal appearance, same-page bounds and annotation flags while preserving widget identity, page annotation position, actions, StructParent and existing structure object references. Cross-page relocation and new tagged widget creation need further structure ownership profiles. `SetTabOrder` writes the standard R/C/S page Tabs value without changing annotation or structure order; choosing S does not create tags.

Existing NeedAppearances is retained; authoring a new private appearance does not disable regeneration requested by other source widgets. Immutable source snapshots, shared operation cancellation/budgets, explicit signature invalidation, borrowed stream ownership and atomic path writes apply. Core adds no native dependency. Source tests and small independent PDF reader/rendering fixtures do not qualify the full form corpus, interactive viewer round trips, missing creation/regeneration/structure profiles, actual minimum runtimes or final packages. All remain required before production qualification; packing and NuGet publication stay blocked.
