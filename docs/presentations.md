# Presentation conversion source profile

`PdfPresentations.WriteRasterSlides` explicitly exports an image-based PPTX. A caller selects 1–512 PDF pages in exact order (including duplicates), a common slide size of 72–4032 points on each axis, a rendering provider and whole-page opaque rendering options. Each page is rendered once into a lossless embedded PNG; aspect-preserving contain uses centered opaque white margins. No editable text, vectors, font reconstruction or automatic fallback is claimed. Slide positions/sizes use original EMU coordinates (12700 EMU per point), independent of raster DPI. Source snapshots remain unchanged.

`ImportRasterSlides` reads the closed static picture-only profile. It preserves slide order/common size and embedded PNG/JPEG positions, creates PDF image resources, and paints explicit white backgrounds. Inherited master shapes, text, groups, crop rectangles, rotation, animations, linked/external media, effects and extensions reject explicitly. It requires an explicit blank layout, `showMasterSp=0`, white slide backgrounds and rectangular, unmodified embedded pictures. No source actions are executed and no fonts or resources are discovered. This is a deliberately named raster profile; complete editable reconstruction and general presentation input remain mandatory for FP-055.

ZIP/XML use the same finite preflight, expansion/CRC checks, depth/node budgets and offline resolution as spreadsheet data. Rasterization, encoding, package generation and import share one context; pixel limits and cancellation propagate. Output stages before caller writes. Input/output/provider ownership remains with the caller. Four managed target frameworks are supported at source level, subject to the explicitly supplied renderer's platform capability.

`PresentationConversionTests` exercise ordered/repeated pages, common geometry, decoded image pixels, source retention, unsafe external relationships, unsupported text/crops/effects, rendering failure and zero partial publication. Independent presentation/package readers inspect the controlled output. This does not qualify arbitrary presentation objects, native rendering, actual supported hosts or final packages. Requirement status remains Planned.
