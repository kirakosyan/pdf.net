# Static SVG and vector export

FP-052 / queue #65 adds the optional managed `Fluent.Pdf.Formats` assembly. The original SVG source profile imports closed static constructs and exports an explicit opaque PDF vector profile without raster substitution. Complete SVG/CSS/vector/text/image profiles, independent standards/fidelity corpora and runtime/package production qualification remain mandatory. Status stays Planned.

Import supports explicit physical root dimensions, `viewBox`, centered-meet/stretch aspect, nested groups, finite matrix/translate/scale/rotate transforms, local user-space path clips, rect/line/polyline/polygon and M/L/H/V/C/Z path data. Fill/stroke use opaque Gray/RGB-compatible paints, basic names/hex/RGB syntax, line caps/joins/miter/dashes and winding rules. SVG unitless dimensions use96 CSS pixels/inch and PDF72 points/inch. Non-default opacity, gradients, filters, quadratic/smooth/arc paths, arbitrary CSS, external resources and unknown elements/attributes reject. There is no silent omission of an unsupported paint effect.

Text requires caller-selected `PdfFontFallback`, a real explicit shaping provider and text options; it never discovers host fonts. Those bindings explicitly override source family names. The initial text profile is black fill without text stroke, using real shaped PDF glyphs and logical Unicode. Full SVG text layout/decoration/font/CSS semantics remain required work. PNG/JPEG data images need explicit local-image authority and the existing explicit image conversion/color/orientation policy; URL/file references always reject. Scripts, animation, foreign content, stylesheets, DTDs and external entities never run.

Clip geometry may contain local transformed supported paths; mixed child clipping rules and object-bounding-box clips reject. XML is preflighted before allocating its bounded operation-local tree. Input/output/node/depth/geometry/shaping budgets and cancellation flow through one context. Invalid finite arithmetic fails as `Svg.Geometry`; source/codec/provider policy failures remain typed.

`WritePage`/`WritePageFile` export opaque device Gray/RGB paths and nested Forms with their matrices, BBoxes, clips, winding, stroke and dash state as editable SVG. Displayed CropBox/rotation/UserUnit geometry is retained. Images, text, annotations, marked-content/layers, ICC/CMYK/pattern/shading/transparency effects, device hairlines and unsupported operators reject before copying output. An explicit neutral `SA=false` graphics-state resource is accepted; nonneutral stroke adjustment and other extended-state effects remain unsupported. The file variant commits atomically. Complete vector/image/text export and semantic preservation remain mandatory; this profile never substitutes a raster without telling the caller.

Source tests exercise vector/clip/style round trips, CSS-pixel sizing, actual explicit-font text, data-image authority, unsupported active/effect/geometry cases and budgets. Independent CairoSVG renders of the original and exported controlled vector fixture are pixel-identical. Independent MuPDF renders of the original and round-tripped PDF are also pixel-identical; raw CairoSVG-versus-PDF antialiasing differences are retained separately without claiming production visual qualification. Run `eng/verify-format-fixtures.py` after source fixtures, using explicitly provisioned CairoSVG/Pillow/PyMuPDF tools. Reports derive pass fields from explicit checks even under Python optimization.
