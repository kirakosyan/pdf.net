# Metadata and document identity

FP-022 has an original managed source implementation on all four core target frameworks. `PdfMetadata.Inspect` returns a detached passive inventory of raw Info/ID values, decoded Unicode text and validated XMP. `PdfMetadata.Edit` runs a synchronous, thread-owned editor that expires when its callback returns. Each edit stages a new document; snapshots stay immutable. Source signatures require the common explicit invalidation permission for rewrites.

`SetInformation` sets or removes standard/custom Info text. Trapped uses the standard True/False/Unknown name. Date strings preserve their supplied precision and offset; the typed date setters require whole seconds. `SetIdentity` copies caller-selected nonempty bytes; a first identifier pair must be identical. The writer prevents changing the permanent identifier during incremental saves. No operation invents a timestamp, reads the local clock or creates a random identifier. Fixed input and explicit values produce repeatable bytes.

`SetXmp` replaces/removes a raw packet. XML prohibits DTDs and external resolution and has a 16 MiB packet ceiling in addition to shared object/depth/expansion/time limits. Preflight charges nodes and attributes before tree construction; both passes check the operation context. `SetXmpProperty` updates a scalar by namespace URI and local name. Unrelated namespaces, attributes, structured values and language alternatives survive semantically; serialization may change prefixes, whitespace or XML encoding. This is bounded XML/RDF handling, not an XMP schema/conformance validator.

Synchronization requires explicit authority. InformationToXmp maps Title, Author, Subject, Keywords, Creator, Producer, CreationDate, ModDate and Trapped and retains unrelated properties and non-default title translations. Its explicit ModDate also supplies MetadataDate. XmpToInformation rejects structured or ambiguous values and multiple creators that cannot be represented without a caller decision. PreferNewest requires complete Info ModDate and XMP MetadataDate values with explicit representable offsets; equal dates select XMP, as the standard prescribes. Representable partial dates remain partial; an hour-only Info date requires an explicit minute before XMP synchronization (`Metadata.DatePrecisionUnsupported`). Subsecond XMP precision loss is rejected in strict mode and reported with `Metadata.SubsecondPrecisionLoss` in permissive mode.

`PdfMetadata.Remove` performs a full rewrite, drops historical revisions and unreachable objects, removes Info, Metadata/PieceInfo relationships and page/Form LastModified values, and optionally removes IDs. Embedded files require an explicit decision: the default rejects; Retain preserves reachable payload bytes and reports that internal file metadata remains. Remove attachments first when their internal metadata must be absent. This operation removes designated metadata, not arbitrary duplicate text in page content, annotations or embedded file formats. It does not claim complete redaction. Unknown application semantics cannot be inferred from a key name.

All operations share cancellation, deadlines, budgets, borrowed-stream ownership and atomic path save contracts. C#/VB `WriteMetadataPdf` examples execute through the source consumers. Exact final package consumers, full schema/interoperability corpora, all runtime lanes and production qualification remain mandatory. NuGet packing and publication remain blocked.
