# Fluent.Pdf 1.0.0

This release contains the currently implemented managed core profiles. The owner explicitly selected this scope on 2026-10-25. It does not represent completion or production qualification of the full SDK roadmap. The existing roadmap requirements and unfinished issues remain open.

## Included

The single MIT-licensed Fluent.Pdf package supplies net472, netstandard2.0, net8.0 and net10.0 assemblies, XML API documentation, portable symbols, SourceLink and dependency notices. It includes the managed document/page model, bounded PDF syntax and filters, page reading, transactional full/incremental writing, content and geometry, managed drawing/layout profiles, page organization, metadata, annotations, passive navigation, attachments, optional-content layers, form and text/resource inspection/editing profiles, operation budgets, cancellation and explicit provider contracts. Every operation retains its documented supported-profile boundaries and strict diagnostics.

The managed core performs no automatic engine, model or font download. Remote resource access requires explicit caller authority. Stream ownership and single-document mutation rules are documented in the API contract.

## Limits

Only Fluent.Pdf and its symbols are published. Companion assemblies, native workers/engines, browser/HTML capture, OCR models, optional codecs/fonts/shaping, office/other-format adapters, signing providers and GUI/COM/printing integrations are not included in this package. APIs requiring these providers need an explicitly supplied implementation; the presence of an API does not promise a bundled engine or complete format/profile coverage.

Complete standards/accessibility/signature/fidelity coverage, multilingual OCR, broad repair/reconstruction, full native distribution, performance/endurance qualification and the full SDK workflow/corpus roadmap remain unfinished. Do not claim PDF/A, PDF/UA, PDF/X, PDF/E, PAdES, OCR accuracy or full format support based on this release. Issue #93's extended security/fuzz campaign and specialist review remain deferred. Automated malformed-input/resource/isolation regressions and known-defect fixes remain required.

The core package is checked through fresh package-only consumers on Windows/Linux/macOS x64/ARM64, .NET 8/10 and explicit netstandard fallback, plus Windows x86/x64 current and actual 4.7.2 Framework. Reports bind loaded assembly hashes to the candidate package. Those observations verify this release's implemented core profiles, not the full roadmap or arbitrary document interoperability. Independent fixture checks verify generated files separately.

Retained release artifacts contain package/content hashes, test reports, actual runtime observations and scoped VM cleanup receipts.
