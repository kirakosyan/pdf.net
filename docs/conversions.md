# Content detection and source conversion matrix

`PdfConversions.WriteMatrix` publishes machine-readable schema1 entries for the exact nine orchestrated save profiles: supported-vector SVG/static EPS, rendered PNG/BMP/TIFF, fixed raster HTML, XPS/OpenXPS and OFD. It records direction, page limits, explicit provider needs, library targets and Windows/Linux/macOS applicability. Every entry says full format support and production qualification are false. It does not advertise general load orchestration or formats beyond these implemented export paths.

`Export` and `ExportFile` select one exact profile, explicit metadata/rendering/provider configuration and a bounded ordered page list. Capture, parse/render/encode/package phases and precommit progress share a single operation context. Starting and OutputPrepared callbacks run before caller writes; cancellation or callback failure prevents publication. Files use atomic replacement. Streams remain caller-owned. Missing renderers, unsupported vector content, invalid page selection and empty results fail without a substituted document or raster/format fallback.

`Detect` observes content family from bounded signatures, XML roots or canonical package main/MIME identities. A filename extension never determines format and disagreements report `Conversion.ExtensionMismatch`. Ambiguous multi-format packages reject. Plain TeX/CSV/text and unknown encodings require caller selection. Detection is not complete structural/content validation; the selected importer must still validate its exact supported profile. It captures at most64 MiB with the shared ZIP/XML/CRC/resource boundaries and never executes scripts, stylesheets, actions or external resources.

Broader load/save adapter orchestration and the full format/direction matrix, richer options/progress/host capability integration, actual application corpus and supported-host/package production qualification remain mandatory for FP-065, which stays Planned. End-to-end tests exercise every advertised source export entry and prove shared context, nonempty output, family identity and precommit failures.
